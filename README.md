# Style 7 Perfection — Website

Premium herenkapper / barbershop website voor **Style 7 Perfection** in Den Haag.

## Tech
- Pure HTML/CSS/JS — geen frameworks
- Mobile-first responsive design
- Google Fonts (Playfair Display + Inter)
- Scroll-animaties via IntersectionObserver

## Deploy
- **Live:** [style7-perfection.netlify.app](https://style7-perfection.netlify.app)
- **GitHub:** [somename55/style7-perfection](https://github.com/somename55/style7-perfection)

## Lokaal draaien

npx serve .
